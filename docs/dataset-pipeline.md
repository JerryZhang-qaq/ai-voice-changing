# 歌曲数据集处理 · 首测版

训练者确认素材属于同一歌手。歌曲中的和声由切片审查处理，不再作为整曲排除条件。程序不做歌手身份识别、声纹聚类或目标歌手选择。中日测试素材分为两份数据集，不能混为同一歌手训练。以下是 0.0.4 流程；0.0.3 的整曲筛查规则已移除。

## 实际处理顺序

1. 登记不可变源文件，FFprobe 检查格式和时长；FFmpeg 生成浮点母版，保留采样率信息。
2. 带伴奏歌曲通过 MelBand RoFormer unwa FT3 提取人声；干声可按需再次提取。
3. 按需运行 anvuew 温和去混响与 aufr33 降噪。每次比较前后时长、活动包络、弱声、高频比例和对齐，明显信号崩溃或时间变化回退输入并标记复核。
4. 测量声道相位，避免反相下混丢音；修正明确直流偏置。8 kHz 分析代理计算每 20 ms 的音高、置信度和频谱瞬态，原始训练音频保持浮点母版格式。
5. 所有提取后的人声都进入切片。能量滞回、相对活动阈值和停顿规则寻找边界；超长连续演唱使用能量、音高置信度、瞬态及目标长度选择代价较低的边界，保留上下文并标记强制切分。最长期限包含边缘余量，不丢弃尾部。
6. 按片段检查信号、平顶削波、时长/边界和完全/近重复。无稳定音高只产生不确定提示，不能单独删除气声和辅音。严格不足 1 秒的切片直接排除。
7. 默认不运行额外的和声模型。选择“切片和声辅助检查”时，aufr33/viperx Karaoke 模型只读取已经切好的、未被硬规则排除的片段，提供主唱/和声试听候选及检查报告。复杂和声仅标记该片段待复核，不影响同首歌曲的其他片段，也不自动替换训练音频。同一批任务复用和声模型，逐片推理仍增加耗时，该选项默认关闭。
8. 网页默认全部人工复核，用 Y / N 逐片接受或排除，保存为新版本。API 自动模式仅在歌手声明、该片段的和声证据通过且没有风险原因时接受；未开启辅助检查时保留待复核。冻结清单，关联重复来源，按来源划分训练/验证。

## 分离调度与缓存

GPU 步骤按模型处理整批歌曲：先整批提取人声，再按选项整批去混响、降噪，然后分析切片。任务内只有当前模型驻留，切换前释放旧模型；切片辅助检查复用同一会话。训练只保存需要的人声 / 干声 / 清洁声，转换保留可下载的所有声部。

均衡使用混合精度、窗口 256，人声/和声/降噪重叠 4、去混响 2；快速重叠 2，保真沿用 FP32 与重叠 8。允许原生 PyTorch SDPA 自动选择支持的后端，保留 math 后端；保真沿用旧注意力策略。NaN/Inf 或已知不支持的半精度/后端回退 FP32，显存不足尝试窗口减半，记录实际参数及原因；失败不会伪装成成功。模型、配置、来源、用途、精度和策略版本进入缓存身份。默认优先复用已有保真干声，可取消该选项以重做当前模式。

## 自动准入边界

| 证据 | 首测行为 |
| --- | --- |
| 片段疑似复杂和声 | 该片段待复核，允许人工接受或排除；保留整首其余片段 |
| 不足 1 秒、完全重复、极弱信号、严重平顶削波 | 片段排除 |
| 疑似叠唱、近重复、短段、强制边界、清洗损伤、声道歧义 | 待复核 |
| 缺少可靠歌唱证据 | 待复核，保留音频 |
| 仅清洗比较尚未校准或提取导致预期内容变化 | 记录信息；仍由其他风险规则决定准入 |
| 未运行和声辅助检查 | 保留片段，人工试听；不以未检查为通过 |
| 所有必要检查通过 | API 自动模式接受并保护数据；网页仍逐片人工审核 |

片段和声提示规则暂定：候选比主唱低不超过 22 dB、两个声部均有可信音高，扣除八度歧义后相差超过 140 音分；独立重叠至少 0.8 秒且占有效主唱至少 8%，或连续至少 1.2 秒时提示复杂和声。显著同音候选也送复核，不宣称已排除同音叠唱。阈值未在独立人工和声标签集上校准，任何此类提示都不触发整曲弃用。

处理器版本已更新，避免复用旧版“整曲弃用”清单。旧版本保持历史记录；重新批量处理原文件夹会生成全部歌曲的切片，输入、权重和参数相同且缓存完好的人声提取仍可复用。边界编辑后清除旧片段的和声证据，重新人工试听。

人声分离不等于所有伴奏均已去除，和声模型也可能泄漏主唱。首测版自动准入属于可追溯实验规则，尚不具备已测量的污染检出率；页面允许纠正，并保留引擎、权重摘要、参数、分项指标与原因。不能用一个音质总分掩盖不确定性。

## 边界与训练版本

默认核心目标约 8 秒、最长含余量 15 秒，边缘余量各 150 ms。用户可以调整最短/目标/最长、停顿、余量和活动阈值。相邻片段的上下文允许重叠，有效核心区间必须可追溯，训练统计不能把上下文当作新增素材。

网页可查看波形并编辑核心起止时间。编辑读取受保护的工作母版，检查范围和同来源核心重叠，再重做指标及重复检查；生成新清单，改动片段必须重新试听接受。母版或其他必要复核片段已经清理时明确失败，需重新准备。

训练只读取冻结版本中的接受片段及训练组。RVC 适配器从接受片段派生不超过 5.4 秒的训练核心窗口，保留 150 ms 上下文及尾部；检查实际浮点 WAV 字节分桶，避免上游悄悄丢掉长片段。派生窗口记录父区间，RMVPE/HuBERT 输出检查通过后才能训练。

## 后续音质验收

中日真人录音用于实际执行、切片、受控损伤和真实清洗模型检查。当前样本规模有限；未进行独立人工边界/污染标注、盲听和同预算 RVC 对照训练。误删有效歌唱、污染漏放、辅音截断与最终翻唱音质仍需要单独测量。详细证据见 `benchmarks/README.md`。
