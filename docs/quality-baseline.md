# 清洗检查与重复检测：当前实现

这是信号保护基础版，所有阈值均未在真人歌唱标注集上校准。它用于发现明显异常、保留比较证据和防止训练/验证泄漏，不输出音质总分，也歌手身份由训练者确认，独唱检查由另一个和声模块提供实验性证据，不能保证干声纯净度。

## 清洗检查

数据准备中的每次模型处理都保存输入、候选、选择结果、引擎参数及权重摘要。模型输出成功不代表质量合格。

| 场景 | 比较方法 | 默认处理 |
| --- | --- | --- |
| 歌曲→人声 | 时长、峰值、削波记录 | 内容变化是预期，不用频谱/能量损失回退整首歌曲 |
| 人声→去混响/降噪 | 时长、20 ms RMS 包络、弱声、频段比例和包络对齐 | 明显信号崩溃/时长异常/高置信错位回退输入，其余提示复核 |

分块分析工作代理最多 16 kHz，原始/训练音频不使用此代理。立体声先跨全文件测量相位风险再固定声道策略，不在块边界跳换声道；明显反相保留较强声道。分析内存随包络帧数增长，不把整首波形和全部候选长期堆在内存。

暂定信号保护规则：

- 时长差超过 60 ms 时，人声清洗回退；歌曲提取只记录，不退回歌曲。
- 活动区间中位电平下降超过 24 dB，且至少 75% 活动帧同样下降时，回退。小幅整首增益变化不视为损伤。
- 扣除中位增益变化后，超过 15% 活动帧下降 18 dB，记录疑似局部损伤，不独立触发回退。
- 弱声单独检查到活动阈值下方最多 20 dB、最低 -75 dBFS；无稳定 F0 不会成为删音依据。弱声丢失可能是降噪的预期结果，因此只复核。
- 比较 3–8 kHz 与 400–3000 Hz 的能量比例，显著下降只提示；不能由此判断 8 kHz 以上频谱或感知音质。
- 在 ±200 ms 范围估计 RMS 包络错位；偏移超过 60 ms、相关度超过 0.85 且优于零偏移至少 0.05 时回退。恒定长音等缺少变化的信号明确标注无法估计。

这些指标不能完整识别金属音、咬字破坏、音色变化或高音伪影。回退版可能仍有和声/混响；回退不意味着自动接受。自动模式中通过必要检查且没有风险原因的片段可以自动接受，其余送复核。数据集页面提供 A/B 试听；对比音频清理后，清单中的决策、指标和引擎信息仍可追溯。

## 重复检查

完全重复使用有效区间的样本 SHA-256，并计入采样率。近重复先生成 2 kHz 傅里叶低通分析代理，容忍增益、极性和小幅时间偏移，再用波形相关度确认候选；不修改训练音频。

当前范围仅限同一次数据准备任务：时长相差不超过 120 ms，以频谱签名筛出最多 16 个候选，再检查 ±100 ms 偏移。相关度至少 0.992 且重叠比例至少 97% 才标记疑似重复。低包络变化的持续长音缺少录音唯一性证据，因此不作为近重复证据。完全重复仍单独处理。

没有通过检查不等于没有重复。跨任务、歌曲中的局部重叠、较重有损编码、变速和更多候选召回尚未实现；清单记录检测范围、候选数、实际比较数和预算限制。

疑似近重复只进入复核，不自动删除。完全重复及疑似重复都会关联整个来源组，包括已经排除的桥接片段；冻结审查、导出及训练使用同一组划分，关联来源不能分别落入训练与验证。关联后只有一个独立组时明确报告无法建立独立验证集。

## 已执行验证

合成信号验证了增益/极性变化、重采样、弱声/高频损失、局部丢音、信号崩溃、错位、剪裁和反相；实际 FFmpeg 与 worker 集成验证了回退后继续切片、缓存清理后的证据保留、重复来源分组。

单元测试的分离输出由明确的测试替身生成；另外执行的中日真人素材和实际 RoFormer CPU 推理见 `benchmarks/README.md`。GPU 性能、独立标注和最终 RVC 盲听对比仍待完成。
