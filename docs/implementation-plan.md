# 实施与验收计划

## 第一步：数据处理基础

实现来源登记、解码、母版、时间映射、信号分析、约束切片、清单及原因码。先用 CPU 可验证部分建立可重复评测，不以未校准的 AI 质量检测阻塞基础能力。

验收：原件不变；弱声、气声及长音测试明确执行；边界和有效区间可追溯；重复运行生成相同结果；损坏输入得到明确原因而非空成功。

## 第二步：GPU 引擎验证

实测候选分离权重、去混响和 RVC 的安装、调用、音质、显存和速度，固定版本。验证至少一种 40 系配置；更新显卡的支持必须分别有证据，未测型号标记未验证。

验收：完成实际分离与 RVC 转换；音频长度和时间对齐正确；依赖隔离；模型完整性与许可记录齐全。训练与推理分别报告能力，不能用转换成功推断训练成功。

## 第三步：数据清洗与审查闭环

接入分离、清洗比较、污染线索、独唱和声筛查、近重复检查及来源分组；实现 A/B 试听、边界调整和人工纠正。通过标注样本校准规则，报告误删、漏放和复核率。

验收：疑似多人及过度清洗进入复核；每次决定有证据；修改只重跑受影响阶段；数据版本可冻结；验证集无同源与近重复泄漏。

## 第四步：一站式训练与翻唱

实现模型下载与导入、特征/F0 提取、训练、检查点试听、索引与模型包导出，以及歌曲分离、转换和混音。UI 与后端任务事件同步。

验收：从用户音频完成数据集准备、真实训练、模型导出再导入及整首翻唱；取消、失败恢复和服务重启有测试；调整混音不重跑转换。进行同预算数据处理训练对比，发布质量评测与已知限制。

## 发布前

完成 GPU 部署文档、外网访问认证、上传大小与磁盘配额、路径与压缩包校验、模型导入安全边界。第三方 pickle 类模型文件不视为可信数据；解析与加载放入受限工作进程，禁止从未知模型执行任意下载脚本。确定项目许可证并保留第三方声明。

数值质量门槛在首批标注和测量后制定，当前不编造通过率或效果承诺。
