# 中日真人女声首测记录

2026-10-06，在当前 Linux CPU 云机实际执行。中文采用 Opencpop 官方专业女歌手录音，日本采用 NIT-SONG070-F001 女声录音的公开测试样本。不是热门歌手全集；公开样本规模有限，用于第一版流程检查，完整音色训练还需更多授权独唱素材。

| 数据集 | 来源数 | 输入时长 | 切片数 | 有效核心区间 | 强制边界片段 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 中文 Opencpop | 2 | 104.36 秒 | 11 | 94.62 秒 | 2 |
| 日文 NIT-SONG070-F001 | 3 | 136.80 秒 | 22 | 115.16 秒 | 0 |

有效核心包括边界处保留的少量停顿，不等于人工标注的有效歌唱时长。初始切片全部待复核；未在整首上运行和声模型，不能从短片段和声结果自动接受整首来源。日文有 6 段较短、3 段可信有声音高不足，保留供试听，不将气声或辅音据此直接删除。受控增益/极性、完全丢音及局部丢音检查也使用实际歌唱，完整结果见 `dataset-report.json`。

## 真实分离模型

PyTorch 2.7.1+cpu、audio-separator 0.47.0，四种权重和 YAML 完整 SHA-256 与固定清单一致。每次输入 8 秒，窗口 128、重叠 2、批大小 1；这低于产品默认重叠参数，CPU 耗时不可当作 RTX 显卡性能。声部标签匹配真实配置，全部输出维持输入时长。

| 素材 | 操作 | CPU 秒数（含加载） | 结果 |
| --- | --- | ---: | --- |
| 中文 | 人声提取 | 63.06 | 执行完成 |
| 中文 | 和声检查 | 51.32 | passed |
| 中文 | 温和去混响 | 53.68 | 执行完成；弱声损失提示 |
| 中文 | 降噪 | 54.64 | 执行完成 |
| 日文 | 和声检查 | 50.81 | passed |
| 日文 | 温和去混响 | 53.32 | 执行完成 |
| 日文 | 降噪 | 45.79 | 执行完成 |
| 双真人重叠 | 和声检查 | 55.72 | rejected |

中文带伴奏输入来自官方配对混音示例，检查对应干声的变化但不把信号代理指标称为听感评分。去混响中的弱声损失提示会阻止自动接受该候选。双真人重叠由两个原始录音等响度混合构成，模型之后发现 4.12 秒独立重叠，占有效主唱约 60.8%，触发整份弃用；这只是一个已知案例，不是自然复杂和声检出率。

`engine-report.json` 保存每次模型耗时、输出帧数/时长、分项损伤记录、和声证据与测试局限。没有独立人工污染标签或盲听，准确率/召回率保持空值。未执行 RVC 训练，不能据此承诺翻唱音质。

## 浏览器与复现

Playwright 使用实际 Chromium、API 和独立 worker，通过七个页面及真实中文录音的上传→切片→波形→边界编辑→人工接受→ZIP 导出→缓存保护流程；浏览器脚本错误与服务器 500 为零。记录见 `browser-report.json`。

执行 `scripts/benchmark-dataset.py` 获取两份独立本地数据集；加 `--import-workbench` 登记到工作台。固定来源、版本、大小和摘要见 `sources.json`。中文原件许可正文为 CC BY-NC-ND 4.0，处理后音频不随程序包分发；日文 CC BY 3.0 归属声明见 `NIT-SONG070-COPYING.txt`。程序发行包不包含音频和权重。
