- Playwright 对 0.0.3 八页访问、实际文件夹导入、歌手推断、批量处理、Y / N 保存、after / ready ZIP、波形、固定侧栏、用途隔离、伴奏下载、和声下载链接、下载弹窗、手动缓存清理和接受片段保护通过。浏览器脚本错误与服务器 500 均为零。报告见 [0.0.3 浏览器记录](benchmarks/0.0.3-browser-report.json)。GPU 分离/训练及下载在此浏览器运行中使用显式 CPU 测试替身；音频分析、审查、存储和导出执行真实代码。

## 既有真实音频与实机结果

中文 Opencpop 两份原始录音约 104.36 秒、11 段；日文 NIT-SONG070-F001 三首约 136.80 秒、22 段。无独立人工污染标签，因此没有虚构准确率或盲听分数。四类 RoFormer 真实 CPU 推理的参数、耗时、变化和局限见 [基准记录](benchmarks/README.md)。中文素材不随发行包分发。

用户已在原生 Windows / RTX 5080 Laptop GPU 完成上一版依赖安装、实际 CUDA 运算、RMVPE 与 HuBERT 六段提取、真实 RVC 训练，截图确认任务 `71101fd9` 成功登记模型、索引和训练工作目录，并回报程序已能运行。0.0.3 包含已验证的 venv 监督、模块启动、UTF-8 与首次模型导出目录修正。
