# 更新待办

以下事项已记录，尚未实现。当前继续收集 0.0.1 的本机测试反馈，修正版发布保持暂停。

## 界面与交互

- [ ] **界面视觉改版**：采用 Apple 风格的简洁、明亮、宽敞设计，以白色和浅灰为主，统一字体层级、间距、圆角与按钮样式，减少拥挤的卡片和边框。
  - 验收：七个功能页面风格一致，主要操作和状态清晰，页面留白充足。
- [ ] **左侧导航固定，右侧内容独立滚动**：滚动主要内容时，左侧功能栏保持原位；小高度窗口下，左栏需要时可自行滚动。
  - 验收：右侧长页面滚动不会带动左栏，切换功能始终方便可见。
- [ ] **醒目的下载弹窗与进度条**：提交下载后立即显示弹窗；任务排队时明确显示“等待下载”，实际开始后显示“下载已开始”。展示进度条、百分比和已下载/总大小；总大小未知时显示已下载大小与活动进度。
  - 验收：当前文件和整体状态可辨认，完成、失败和取消都有明确反馈；关闭弹窗不取消后台下载，可从任务中心继续查看进度。
- [ ] **训练过程可视化**：提供训练详情面板，直观展示“生成训练音频 → RMVPE 音高提取 → HuBERT 内容特征提取 → RVC 训练 → FAISS 索引构建”的阶段状态和进度；训练期间展示当前轮数/总轮数、批次进度、已用时间、速度与预计剩余时间、损失曲线、GPU 利用率及显存占用，以及检查点保存状态。
  - 验收：指标来自真实引擎日志或设备采样；无法获取的指标明确显示未知，预计时间按实际速度估算，阶段进度不使用固定的“0/1”冒充。刷新页面可恢复已记录的进度和曲线，失败时定位具体阶段并展示错误日志。音质仍通过试听确认。

## 首测问题排查

- [ ] **RMVPE 阶段退出码 143 且日志为空**：用户在 Windows 原生首测中遇到任务在“RMVPE 音高提取”阶段失败，页面仅显示退出码 143 和“暂无引擎日志”。原因尚未确认；排查引擎监督进程的父进程检查、取消/退出行为，以及日志写入与读取。
  - 验收：在实际 Windows 虚拟环境中验证引擎启动；正常启动、主动取消和父进程退出有明确区分。即使引擎尚未输出，也保留启动、终止和退出码的诊断记录，失败原因可从任务页面获取。

## 数据集处理

- [ ] **审查使用 Y / N 按钮**：将每个切片的审查决定下拉列表替换为两个直接可点的选项：Y（接受）、N（排除）。未作选择的待复核片段保持待复核，点击任一选项后清楚显示当前选择，可在保存前切换。
  - 验收：一次点击即可作出接受或排除决定；文字和选择状态清晰，键盘也能聚焦并操作；继续通过“保存审查为新版本”保存决定，并保护已接受切片。
- [ ] **清理缓存后的数据集状态与重复导入反馈**：清理会移除未保留、未接受的切片，但永久清单仍留在数据集列表；重复执行测试集导入又生成新清单，目前同名版本难以区分。
  - 验收：清理前明确提示影响到哪些待复核数据集及多少切片；清理后列表显示缺失片段数量和“需要重新准备”状态，并展示版本创建时间。测试集重复导入时识别已有完整结果，提示复用或重新生成；旧清单继续可追溯。已接受的切片保持清理保护。
- [ ] **自动排除不足 1 秒的切片**：按切片实际音频时长判断，严格小于 1.0 秒时直接标记为“排除”，记录“切片不足 1 秒”的原因并汇总数量，原始素材继续保留。
  - 验收：自动切片与边界编辑后的片段均遵守该规则；不足 1 秒的片段不进入训练或训练集导出。比较使用实际时长而非界面四舍五入值，恰好 1.0 秒不因该规则被排除。
