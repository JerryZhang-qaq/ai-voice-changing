## 数据集处理

- [ ] **以歌手名字组织文件夹并整夹处理**：导入的音频和切片后的音频都必须归属歌手，并存放在以歌手名字命名的文件夹下；文件存储与界面展示统一按该结构管理。导入时选择或创建歌手，目录中分别存放原始素材和各版本切片，例如 `歌手名/原始素材/`、`歌手名/切片数据集/版本/`。
  - 验收：不同歌手的训练音频分开存放；自动切片、清洗等操作通过选择整个歌手文件夹提交，默认批量读取该歌手的原始素材区，处理结果归档至该歌手目录。现有音频和数据集提供歌手归属与迁移入口，迁移后已保存的审查决定、版本关系和任务引用保持有效。
- [ ] **审查使用 Y / N 按钮**：将每个切片的审查决定下拉列表替换为两个直接可点的选项：Y（接受）、N（排除）。未作选择的待复核片段保持待复核，点击任一选项后清楚显示当前选择，可在保存前切换。
  - 验收：一次点击即可作出接受或排除决定；文字和选择状态清晰，键盘也能聚焦并操作；继续通过“保存审查为新版本”保存决定，并保护已接受切片。
- [ ] **清理缓存后的数据集状态与重复导入反馈**：清理会移除未保留、未接受的切片，但永久清单仍留在数据集列表；重复执行测试集导入又生成新清单，目前同名版本难以区分。
  - 验收：清理前明确提示影响到哪些待复核数据集及多少切片；清理后列表显示缺失片段数量和“需要重新准备”状态，并展示版本创建时间。测试集重复导入时识别已有完整结果，提示复用或重新生成；旧清单继续可追溯。已接受的切片保持清理保护。
- [ ] **自动排除不足 1 秒的切片**：按切片实际音频时长判断，严格小于 1.0 秒时直接标记为“排除”，记录“切片不足 1 秒”的原因并汇总数量，原始素材继续保留。
  - 验收：自动切片与边界编辑后的片段均遵守该规则；不足 1 秒的片段不进入训练或训练集导出。比较使用实际时长而非界面四舍五入值，恰好 1.0 秒不因该规则被排除。
- [ ] **长期保留文件的手动删除入口**：用户可主动选择旧数据集、原始素材及其他长期保留产物，预览依赖影响与释放空间后执行删除；缓存清理继续保护长期保留数据，活动任务使用中的项目保持保护。
  - 验收：提供独立于缓存清理的删除操作，明确显示受影响的版本和引用；保留未选中的有效素材、模型与成品。用户已暂停本次实际删除，当前仅记录功能需求。
