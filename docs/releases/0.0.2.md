# 0.0.2 · 早期测试版（待发布）

修复 0.0.1 在 Windows 上双击安装入口闪退、路径及命令被错误拆分的问题。

## 修复

- 五个 Windows CMD 入口统一使用 ASCII 内容和 CRLF 换行，打包时强制校验并转换，避免 Linux 打包产生不兼容的批处理文件。
- 安装、启动、诊断、GPU 测试和测试数据准备均显示启动提示；失败保留窗口并返回原始退出码。
- 未完整解压、缺少虚拟环境时给出明确提示。
- 安装器显示阶段进度，保存 `runtime/diagnostics/install-*.log`，Python 安装输出及时显示。
- 修正分离引擎固定的 ONNX Runtime GPU 版本：从不存在的 `1.20.1` 改为提供 Python 3.12 Windows x64 安装包的 `1.20.2`。
- 安装器先刷新 PATH，并通过实际 Python 路径、启动器和注册表检查 Python 3.12 x64；已安装但没有 `py` 启动器时仍能复用，winget 的“没有可升级版本”不再作为安装失败。
- 增加原生 Windows 回归检查：在含中文、空格和特殊字符的路径下启动真实 CMD/PowerShell，验证安装失败后窗口等待用户输入和退出码保留。
- 修正 Windows 虚拟环境中引擎监督进程的父进程判断：以真实 worker 句柄检查存活，兼容 Python 转发进程，避免引擎尚未启动就误返回 143。日志记录引擎启动、停止及退出码。
- RVC 训练改用 `python -m train.train` 启动，避免 `train/train.py` 遮蔽同名包产生循环导入；引擎日志统一为 UTF-8 并及时输出。
- 训练前创建 `assets/weights` 输出目录，修正首次训练执行了多轮却无法导出推理模型的问题；任务单独显示模型导出校验阶段。

## 下载和运行

下载 `VoiceWorkbench-0.0.2-Windows.zip`，完整解压到新的文件夹，先运行 `Install-Windows.cmd`，安装完成再运行 `Start-Windows.cmd`。

若已经在 0.0.1 目录生成运行数据，可以将新包中的五个 `*-Windows.cmd`、`scripts/install-windows.ps1`、`scripts/windows-prerequisites.ps1` 和 `scripts/separation-constraints.txt` 复制覆盖到原目录，再运行安装入口。保留原有 `runtime`、`.venv` 和模型文件。

目标为 Windows 10/11 原生运行、NVIDIA RTX 40 系及更新显卡。首测包包含网页，模型权重另行下载。实际 GPU 安装、RVC 训练和最终翻唱质量仍需目标电脑验收。
