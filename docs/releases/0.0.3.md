# 0.0.3 · 早期测试版

训练素材改为按歌手整夹导入、批量处理、Y / N 审核和保存新版本。训练与转换素材使用独立入口和物理目录，所有产物使用实际歌手、原曲名和处理参数命名。

## 从 0.0.1 覆盖更新

1. 下载并完整解压 `VoiceWorkbench-0.0.3-Windows.zip`，先关闭旧工作台启动窗口。
2. 双击新包中的 **`Update-Windows.cmd`**，在文件夹选择窗口选中原来的 `D:\VoiceWorkbench-0.0.1` 安装目录。也可执行 `Install-Windows.cmd -TargetDirectory "D:\VoiceWorkbench-0.0.1"`。
3. 等待安装完成，运行**原目录中的** `Start-Windows.cmd`。原目录名字可以继续保留 0.0.1，界面版本会显示 0.0.3。

按本次更新要求，首次升级会删除旧的原始音源、切片、数据集版本、训练数据导出包及相关闲置缓存。**已训练模型、索引、转换结果、混音成品、训练工作目录、基础权重和虚拟环境保留。** 清理只执行一次；重复运行更新不会删除升级后新导入的数据。升级前目录清单备份与执行记录保存在原目录 `runtime/diagnostics/`；清单备份不包含被删除的音频。请在升级前自行留好仍需使用的原始素材。

安装器复用原目录的 `.venv` 和两个 GPU 引擎环境；已符合固定版本的 Torch 不重复下载，其他依赖由 pip 核对。窗口失败时保留错误、退出码和完整日志。运行中的工作进程会阻止升级。

首次安装运行 `Install-Windows.cmd`，在目录选择窗口选择本次解压目录。

## 本版功能

- 明亮、宽敞的界面，左侧导航固定，右侧内容独立滚动；八个功能入口。
- 训练音源文件夹自动推断歌手名，可修改；单层文件夹批量导入，重复音源复用，导入失败回滚。
- 人声提取使用 MelBand RoFormer unwa，复杂和声筛查使用 aufr33/viperx Karaoke；检测复杂和声整份弃用，按需去混响、降噪及处理损伤检查。
- 严格排除实际长度不足 1 秒的切片，审核、编辑、导出及训练再次检查。Y 接受 / N 排除，保存审查为新版本；切片分页、缺失数量与版本时间。
- 干声合集命名为 `<歌手>-after.zip`，已审查训练集为 `<歌手>-ready.zip`。训练模型带歌手、版本、采样率、轮数、批大小及可观测的实际步数；内部 ID 仅用于区分文件和版本。
- 每项后台操作在执行位置显示进度、阶段、耗时、错误、取消和日志，刷新或切换页面后恢复；任务中心保留全局列表。
- 训练可视化显示真实轮次、批次、损失曲线、显存和 GPU 利用率、预计剩余时间及检查点状态。没有总工作量的阶段使用活动进度条。
- 下载开始立即显示醒目的任务弹窗，区分排队、下载、校验与完成，显示实际字节进度。
- 独立的转换素材入口，一键分离人声、伴奏、主唱和和声，支持试听和下载。变调 ±24 半音、索引、清辅音保护、响度和增益均可调。
- 翻唱可保留原和声；混音支持转换主唱、伴奏和可选和声三轨，导出 WAV / FLAC / MP3。
- 手动清理所有闲置缓存，包括人为保留的缓存与检查点；原件、数据集、模型和成品可以独立预览并永久删除，活动任务占用的文件仍受保护。
- 包含此前 Windows 安装入口、依赖约束、venv 进程监督、UTF-8 日志、RVC 模块启动和模型输出目录修复。

## 验证范围

CPU 数据处理、API、存储、命名、三轨混音、升级幂等及前端构建经过自动化检查；浏览器流程使用真实音频、真实 API 和数据处理，对 GPU 分离/训练及大文件下载使用明确标记的测试替身，不能据此判断 GPU 性能或音质。原生 Windows 检查覆盖 CMD、PowerShell、venv 进程管理和升级行为。0.0.1 的 RTX 5080 Laptop GPU 训练已由用户验证；0.0.3 新训练观测和 GPU 流程仍需本机复测。

早期测试版不包含真人音频或第三方模型权重。和声与污染筛查仍需人工试听；短测试集适合验证流程，正式训练应补充充分的时长、音域和唱法覆盖。
