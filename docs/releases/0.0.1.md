# 0.0.1 · 早期测试版

这是 AI 翻唱工作台的早期测试版，用于在目标电脑上验证从素材处理、RVC 训练到翻唱导出的完整流程。

## 下载和运行

下载 `VoiceWorkbench-0.0.1-Windows.zip`，解压后先运行 `Install-Windows.cmd`，安装完成再运行 `Start-Windows.cmd`。

目标为 Windows 10/11 原生运行、NVIDIA RTX 40 系及更新显卡。首测包包含构建后的网页，不需要 Node.js 或 WSL2；基础模型和分离权重在程序资源页另行下载。详细说明见仓库的 `docs/windows.md`。

## 本版功能

- 素材上传、人声提取、复杂和声整份弃用、去混响和降噪。
- 独唱切片、清洗损伤检查、重复检测、波形与边界编辑、数据集审核和导出。
- RVC 模型训练及继续训练、模型与索引导入、音色转换、一键翻唱与混音。
- 固定版本模型资源下载和完整性校验、任务管理、中间缓存清理。

## 已验证与待验证

65 项自动化测试、网页生产构建和真实浏览器操作流程已通过。四类 RoFormer 分离模型已完成真实 CPU 推理检查。

当前云环境没有 NVIDIA GPU，Windows 实机安装、实际 RVC GPU 训练和最终翻唱听感尚待验收。提供诊断和 GPU 测试入口，不将 CPU 测试记为 GPU 验收。

中文和日文女声样本各自独立，只有约两分钟，用于数据处理流程测试；正式训练需要补充更多同一位歌手的清晰独唱素材。自动清洗规则仍需扩大样本、人工标注和听感校准。

程序包不包含用户音频、测试音频、模型权重或虚拟环境。
