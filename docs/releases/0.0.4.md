# 0.0.4 · 早期测试版

批量训练素材现在先对全部歌曲提取人声，再切片、逐片试听审核。复杂和声只提示相关片段，由人工 Y / N 决定；不再弃用整首歌曲。旧版被整曲筛查跳过的素材可以重新准备，完整的人声提取缓存优先复用。

## 覆盖更新

1. 关闭当前工作台启动窗口，完整解压 `VoiceWorkbench-0.0.4-Windows.zip`。
2. 运行新包的 **`Update-Windows.cmd`**，选择**现在实际使用的安装目录**，例如 `D:\VoiceWorkbench-0.0.3`。
3. 等待更新完成，运行日志所指目录的 **`Start-Windows.cmd`**。目录名可继续保留 0.0.3，页面版本应显示 0.0.4。

本次更新保留全部现有素材、切片、数据集、缓存、模型、基础权重和虚拟环境。匹配固定版本的依赖跳过安装，缺失或不匹配时补装。升级前备份清单，核对包内文件摘要；活动工作进程阻止覆盖。确认目标目录正常后再删除解压包。首次安装仍使用 `Install-Windows.cmd`。

## 分离与批量处理

- **均衡（默认）**：混合精度、窗口 256，人声 / 和声 / 降噪重叠 4，去混响重叠 2。
- **保真**：保留 FP32、窗口 256、重叠 8 与旧注意力策略。
- **快速**：混合精度、重叠 2，先试听边缘和伴奏残留，再用于正式训练。
- 均衡与快速允许 PyTorch 原生 SDPA 自动选择支持的后端，保留 math 后端，无新增 CUDA 插件依赖。数值异常及已知半精度/后端不支持时回退 FP32；显存不足尝试窗口减半，记录实际执行参数与原因。
- GPU 工作按模型集中处理整批，同一阶段复用模型；只有当前模型驻留，切换前释放上一模型。可选切片和声检查也复用会话。取消及超时释放监督进程和临时目录。
- 训练只写出所需的人声、干声或清洁声，节省不使用的伴奏等文件；转换仍保留伴奏和和声下载。
- 默认关闭切片和声辅助检查，全部片段人工复核；去混响、降噪按需开启。严格不足 1 秒的切片仍排除。

## 验证范围

真实 unwa RoFormer 与同一 8 秒中文带伴奏片段在 CPU FP32 下对照重叠 8 / 4 / 2：推理分别为 **124.328 / 71.323 / 47.060 秒**，输出时长相同且采样有限，后两次复用权重。这验证 CPU 短片段重叠收益与模型复用，**不是 RTX 5080 或 CUDA 混合精度实测，也不能代替 A/B 试听**。

完整 CPU 套件、前端构建、八页浏览器流程和原生 Windows CI 验证数据处理、进度、缓存、进程监督与覆盖更新。浏览器 GPU 核心与资源下载使用显式替身；真实模型有独立报告。[验证记录](../progress.md)、[性能报告](../benchmarks/0.0.4-separation-report.json)。

包内 `scripts/benchmark-separation.py` 可在分离引擎环境里生成三种模式的速度报告与试听输出，见 [Windows 指南](../windows.md)。目标 GPU 的 AMP/SDPA、整批耗时与听感仍需本机复测。发行包不含用户音频或第三方权重。
